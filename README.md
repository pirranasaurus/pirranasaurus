**Grimoire** — A Matrix-themed Textual TUI for CTF tool references. Fuzzy search through nmap, ffuf, gobuster and more, all in the terminal. Built for tinkerers, by a tinkerer.

**infiniteinterest** — My blog. Notes from the lab on cyber security, Python, and whatever rabbit hole I've fallen down this week.
